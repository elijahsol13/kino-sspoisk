# Kino → SSpoisk

**Удобный переход с Кинопоиска на SSpoisk для фильмов и сериалов.**

Небольшое бесплатное расширение для браузера: ищите название на Кинопоиске, открывайте карточку и нажимайте **▶ Смотреть онлайн** — соответствующая страница SSpoisk откроется в новой вкладке.

## Как установить

**Если скачали установщик для Windows или Mac:** запустите файл, выберите браузер и выполняйте подсказки в окне. Мастер сам покажет нужную папку и откроет страницу расширений. Останутся три действия:

1. В открывшейся вкладке **«Расширения»** включите **«Режим разработчика»** (Developer mode).
2. Нажмите **«Загрузить распакованное расширение»** (Load unpacked).
3. Выберите папку **Extension**, которую открыл установщик. Значок появится в браузере.

**Если скачали ZIP:** распакуйте его в постоянное место (например, «Документы») и выполните те же действия, выбрав папку **Kino-SSpoisk** с файлом `manifest.json` внутри. После установки папку перемещать или удалять нельзя.

> **Предупреждения безопасности.** Установщики пока не подписаны платными сертификатами разработчика. Windows SmartScreen или macOS Gatekeeper могут предупредить о неизвестном издателе. Проверяйте, что скачиваете файл с [официальной страницы релиза](https://github.com/elijahsol13/kino-sspoisk/releases/latest). На Mac после попытки запуска может понадобиться разрешить открытие в разделе **«Системные настройки → Конфиденциальность и безопасность»**.

## Как пользоваться

1. Нажмите значок **🧩 «Расширения»** возле адресной строки и закрепите **Kino → SSpoisk** для удобства.
2. Откройте расширение, введите название фильма или сериала и нажмите **Enter** или кнопку поиска.
3. На оригинальном Кинопоиске выберите нужный фильм или сериал из результатов.
4. В правом верхнем углу его карточки нажмите оранжевую кнопку **▶ Смотреть онлайн**. Соответствующая страница SSpoisk откроется в новой вкладке.

Необязательно искать через расширение: можно сразу открыть карточку фильма или сериала на Кинопоиске — кнопка появится и там. На страницах поиска кнопки нет.

## Если что-то не получается

- **Не видно кнопки:** убедитесь, что открыта карточка фильма или сериала на Кинопоиске, и перезагрузите вкладку.
- **Не видно значка:** откройте меню 🧩 рядом с адресной строкой и закрепите расширение.
- **SSpoisk не открылся:** доступность стороннего сайта и наличие видео не зависят от расширения.
- **Нужны картинки с подсказками:** в репозитории есть отдельная [HTML-инструкция](START_HERE.html) с иллюстрациями. Её можно скачать и открыть в браузере.

## О проекте

Kino → SSpoisk — независимое расширение на Manifest V3 с открытым исходным кодом. Оно реагирует на карточки фильмов и сериалов на `kinopoisk.ru`, выполняет поиск на оригинальном Кинопоиске и открывает соответствующий адрес на `sspoisk.ru` по нажатию пользователя.

Расширение не требует логина, API-ключей и доступа к истории браузера. Оно не хранит каталог фильмов и не предоставляет видеоконтент. Кинопоиск и SSpoisk — сторонние сервисы, проект с ними не аффилирован. **Не вводите пароль от Кинопоиска на сторонних сайтах.**

<summary><b>Разработчикам: исходники, сборка и тесты</b></summary>

Исходники расширения: `manifest.json`, `links.js`, `content.js`, `content.css`, `popup.html`, `popup.js`, `icon.png`. Установщики: `installer/windows.cs` (Windows Forms) и `installer/macos.m` (Cocoa). Автоматическая сборка и публикация релизов: `.github/workflows/release.yml`.

Проверить локально:

```bash
node --test tests/extension.test.cjs
python3 -m unittest discover -s tests -p '*_test.py'
```

Собрать ZIP и DMG на macOS: `python3 installer/build.py`. Windows EXE собирается в GitHub Actions на Windows runner. Итоговые файлы доступны в [Releases](https://github.com/elijahsol13/kino-sspoisk/releases).

</details>
