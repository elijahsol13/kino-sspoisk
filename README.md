# Kino → SSpoisk

**Удобный переход с Кинопоиска на внешний сайт для фильмов и сериалов.**

Небольшое бесплатное расширение для браузера: ищите название на Кинопоиске, открывайте карточку и нажимайте **▶ Смотреть онлайн** — соответствующая страница kinokino.win откроется в новой вкладке.

> **Можно вообще ничего не устанавливать.** Откройте карточку фильма или сериала на Кинопоиске и в адресной строке **замените весь домен `kinopoisk.ru` на `kinokino.win`**, сохранив путь: например, `kinopoisk.ru/film/123/` → `kinokino.win/film/123/`. Расширение просто делает этот переход одной кнопкой.

## Как установить

**Если скачали установщик для Windows или Mac:** запустите файл, выберите браузер и выполняйте подсказки в окне. Мастер сам покажет нужную папку и откроет страницу расширений. Останутся три действия:

1. В открывшейся вкладке **«Расширения»** включите **«Режим разработчика»** (Developer mode).
2. Нажмите **«Загрузить распакованное расширение»** (Load unpacked).
3. Выберите папку **Extension**, которую открыл установщик. Значок появится в браузере.

**Если скачали ZIP:** распакуйте его в постоянное место (например, «Документы») и выполните те же действия, выбрав папку **Kino-SSpoisk** с файлом `manifest.json` внутри. После установки папку перемещать или удалять нельзя.
