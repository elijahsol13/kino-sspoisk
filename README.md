# Kino → SSpoisk

Небольшое расширение для браузеров на Chromium (Chrome, Brave, Яндекс, Edge, Opera и др.): поиск фильмов и сериалов на Кинопоиске и кнопка для открытия соответствующей карточки на SSpoisk. Локальная установка в Яндекс Браузере может быть ограничена.

## Скачать и установить (без терминала)

Все три файла доступны на [странице загрузок](https://github.com/elijahsol13/kino-sspoisk/releases/latest). Выбери **один**:

| Система | Файл | Что делать |
| --- | --- | --- |
| **Windows 10/11** | `Kino-SSpoisk-Setup.exe` | Скачай → двойной щелчок → «Далее» в окошках. Не нужны терминал и PowerShell. |
| **macOS Intel / Apple Silicon** | `Kino-SSpoisk-macOS.dmg` | Скачай → двойной щелчок по DMG → двойной щелчок по приложению «Установить Kino-SSpoisk» → «Далее». |
| **Любая система: вручную** | `Kino-SSpoisk-manual.zip` | Распакуй ZIP, внутри краткая инструкция `КАК_УСТАНОВИТЬ.txt`. |

Мастер **сам копирует расширение в постоянную папку** и открывает страницу расширений выбранного браузера. Дальше показывает, как включить режим разработчика и через «Загрузить распакованное» выбрать нужную папку. Это обязательный ручной шаг безопасности Chromium. Папку после установки перемещать не нужно.

**Если компьютер показывает предупреждение:** установщики не имеют платных сертификатов разработчика. Windows SmartScreen может попросить подтвердить запуск. На Mac может понадобиться открыть **Системные настройки → Конфиденциальность и безопасность → Открыть всё равно** после попытки запуска. Скачивай только из этого репозитория или от знакомого.

В **Firefox** неподписанное дополнение загружается только временно и исчезает после перезапуска; для постоянного нужно подписание Mozilla. **Яндекс Браузер** в некоторых версиях ограничивает локальные расширения.

## Установка в Chrome, Brave и других браузерах Chromium

1. Открой страницу расширений: Chrome — `chrome://extensions`, Brave — `brave://extensions`, Яндекс — `browser://extensions`, Edge — `edge://extensions`, Opera — `opera://extensions`.
2. Включи **Режим разработчика** (Developer mode).
3. Нажми **Загрузить распакованное расширение** (Load unpacked).
4. Выбери распакованную папку `Kino-SSpoisk` (внутри которой находится `manifest.json`).
5. При необходимости закрепи иконку расширения в панели браузера.

В Firefox: `about:debugging` → **Этот Firefox** → **Загрузить временное дополнение** → выбрать `manifest.json` в папке расширения. Установка только на текущий сеанс; для постоянной нужен подписанный Mozilla пакет.

## Использование

1. Нажми на иконку **Kino → SSpoisk** в панели браузера.
2. Введи название фильма/сериала, нажми **Enter** или **Найти на Кинопоиске**.
3. В новой вкладке откроются результаты поиска на оригинальном Кинопоиске. Выбери нужную карточку.
4. На странице `/film/ID/` или `/series/ID/` в правом верхнем углу появится оранжевая кнопка **▶ Смотреть онлайн**.
5. Нажатие откроет `https://sspoisk.ru/film/ID/` или `https://sspoisk.ru/series/ID/` в новой вкладке, сохранив карточку Кинопоиска открытой.

Расширение не требует регистрации, разрешений на чтение вкладок или API-ключей. Работает только на Кинопоиске, переход выполняет по нажатию.

SSpoisk — отдельный сторонний сайт, не связанный с Кинопоиском или этим расширением; его доступность и содержимое не контролируются расширением. Не вводи там пароль от своего аккаунта Кинопоиска.

## Проверка

Проверка исходников и упаковки из корневой папки:

```sh
node --test tests/extension.test.cjs
python3 -m unittest discover -s tests -p '*_test.py'
```

Сборка ZIP и `.dmg` на macOS: `python3 installer/build.py`. Сборка Windows `.exe` выполняется из `installer/windows.cs` на Windows с помощью стандартного компилятора .NET Framework (`csc.exe`), который встраивает `dist/Kino-SSpoisk-manual.zip` как ресурс `KinoExtension`. Готовые `.exe`, `.dmg` и `.zip` автоматически публикуются в [GitHub Releases](https://github.com/elijahsol13/kino-sspoisk/releases/latest) через `.github/workflows/release.yml` после успешных проверок.

После изменения файлов открой страницу расширений своего браузера, нажми **Обновить** на карточке расширения и перезагрузи страницу фильма.
