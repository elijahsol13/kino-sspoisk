# Kino → SSpoisk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Установимое расширение Brave для поиска на Кинопоиске и перехода с карточки фильма или сериала на SSpoisk.

**Architecture:** `links.js` содержит две чистые функции построения адреса; `popup.html/js` открывает поиск, `content.js/css` встраивает кнопку в страницу. Без зависимостей и сборки.

**Tech Stack:** Chrome Manifest V3, JavaScript, CSS, Node.js built-in test runner.

**Spec:** `docs/superpowers/specs/2026-10-23-kino-extension-design.md`.

## Global Constraints

- Работать только на `kinopoisk.ru` и `www.kinopoisk.ru`.
- Результаты поиска открывать на оригинальном Кинопоиске; SSpoisk только по нажатию кнопки на карточке.
- Новая вкладка для обоих переходов; никаких сетевых запросов из расширения.

## Review Focus

- URL другого сайта не должен генерировать ссылку SSpoisk.
- Разделы поиска и дополнительных материалов не должны показывать кнопку.
- Сериалы `/series/<id>/` должны обрабатываться наравне с фильмами `/film/<id>/`.
- Пробелы и кириллица должны корректно кодироваться в поисковом запросе.
- SPA-переход с карточки на другую страницу должен убирать кнопку.
