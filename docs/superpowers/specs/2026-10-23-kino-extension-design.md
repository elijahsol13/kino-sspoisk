# Kino → SSpoisk: дизайн расширения

**Статус:** согласовано пользователем 23 октября 2026 года.

- Для Brave/Chrome (Manifest V3), без сервера, API, оплаты и сборки.
- Иконка в панели браузера открывает маленький popup с полем поиска. Enter/кнопка открывают результаты поиска на оригинальном Кинопоиске в новой вкладке; выбор результата остается за пользователем.
- На страницах карточек `/film/<число>/` и `/series/<число>/` Кинопоиска появляется фиксированная кнопка «▶ Смотреть онлайн» в правой верхней части экрана.
- Кнопка открывает `https://sspoisk.ru` с тем же путем в новой вкладке. Сторонний сервис может быть недоступен; проверка содержимого/прав на него не входит в расширение.
- Кнопка сохраняется/исчезает при переходах внутри Кинопоиска без полной перезагрузки страницы.
- Скрипт работает только на `kinopoisk.ru`/`www.kinopoisk.ru`, не читает аккаунт и не запрашивает дополнительные разрешения.

**Рассмотренные подходы:** расширение с кнопкой только на панели (меньше кода, но лишний клик); userscript (нужна отдельная установка Tampermonkey); выбран Manifest V3 с popup и кнопкой на странице — один пакет для нужного сценария.

**За рамками первого релиза:** автоматический выбор фильма по названию, обращение к сторонним API, проверка наличия плеера, публикация в магазине расширений.
