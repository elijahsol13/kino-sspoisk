Установка в браузер: 3 шага

После запуска мастера установки файлы уже лежат в постоянной папке. Осталось разрешить локальную установку в браузере. Если скачали ZIP, сначала распакуйте его в постоянную папку, например «Документы».

1

Откройте «Расширения»

Мастер откроет нужную вкладку сам. При ручной установке используйте адрес браузера из подсказки ниже.

2

Включите режим разработчика

Найдите переключатель «Режим разработчика» (Developer mode) — обычно справа вверху.

3

Выберите папку

Нажмите «Загрузить распакованное расширение» (Load unpacked). При установке через мастер выбирайте папку Extension, при установке из ZIP — Kino-SSpoisk.

Адреса вкладки «Расширения»: Chrome — chrome://extensions · Brave — brave://extensions · Edge — edge://extensions · Opera — opera://extensions · Яндекс — browser://extensions.

Firefox: локальная загрузка работает только временно: about:debugging#/runtime/this-firefox → «Загрузить временное дополнение» → выбрать manifest.json. После перезапуска Firefox дополнение исчезнет. Для постоянной установки нужна версия, подписанная Mozilla.
Не удаляйте папку с расширением. Браузер использует файлы прямо из неё. Мастер сам сохраняет их в постоянное место. В некоторых версиях Яндекс Браузера локальная установка может быть недоступна.

Как пользоваться

  1. Нажми значок Расширения 🧩 возле адресной строки и, если нужно, закрепи Kino → SSpoisk на панели.
  2. Открой его и введи название фильма или сериала. Нажми Enter или кнопку поиска.
  3. В новой вкладке откроются результаты поиска на Кинопоиске. Выбери нужную карточку.
  4. В правом верхнем углу карточки нажми оранжевую кнопку «▶ Смотреть онлайн»: откроется соответствующая страница SSpoisk в новой вкладке.

Частые вопросы

Значка расширения не видно

Откройте меню 🧩 рядом с адресной строкой и закрепите Kino → SSpoisk на панели инструментов.

Кнопка «▶ Смотреть онлайн» не появилась

Проверьте, что открыта именно карточка фильма или сериала на Кинопоиске, и обновите вкладку. На странице результатов поиска кнопка не появляется.

Компьютер предупреждает о неизвестном разработчике

Установщики опубликованы без платной цифровой подписи. Windows SmartScreen и macOS Gatekeeper могут показывать предупреждение. Убедитесь, что файл скачан с официальной страницы релизов этого репозитория. На Mac после попытки открытия может потребоваться разрешить запуск в «Системные настройки → Конфиденциальность и безопасность».

Страница SSpoisk не загружается

SSpoisk — отдельный сайт. Расширение только открывает соответствующий адрес, поэтому доступность страницы и наличие видео зависят от внешнего сервиса.

Независимый бесплатный проект. Расширение не связано с Кинопоиском и SSpoisk, не предоставляет видео и не требует логина или API-ключей. Не вводите пароль от Кинопоиска на сторонних сайтах. Исходный код на GitHub ↗
